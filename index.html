How it works

Six stages, from approval to paid job

The trade only touches the last stage. Everything before it runs on its own every day.

01 · Collect

Find approvals

Every day, new council approvals in your area are picked up.

  • Pools, homes, granny flats
  • Address, cost of works, builder, date
02 · Understand

Read each project

Each project is read and sorted by type.

  • Pool, new home, granny flat, knockdown-rebuild, dual occupancy
  • Lot size and property details
  • Builder name cleaned up
03 · Score

Rank for your trade

Each project gets a 0–100 score for this business.

  • Job type fit
  • Cost of works
  • Distance from base
  • Lot size
04 · Time

Wait for the right moment

A letter about a garden lands when the build is nearly done, not on approval day.

  • Delay per project type
  • Adjustable per trade
05 · Reach

Post the letter

A branded letter goes to the site address. Builders get a business email.

  • Print-and-mail service
  • Monthly cap
  • Never mails an address twice
06 · Track

Count what worked

Every reply is tied back to its letter.

  • QR scans and tracked calls
  • Quote → won pipeline
  • Monthly return report
